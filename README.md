# Gece Üçünde Duvara Bakan Kedi Analizörü

Bu depo, saat 03:00'te duvara bakan kedilerin **niyetini**, **hukuki statüsünü** ve **duygusal yükünü** çözdüğünü iddia eden bir yazılımdır.

İddia büyüktür. Kanıt küçüktür. Özgüven sonsuzdur.

## Neden var?

Çünkü birileri durduğu yerde bir şeye takıldı. Takılan şey kedi değildi, duvardı. Duvardı ama kedi bakıyordu. Bakıyordu ama açıklama yoktu. Açıklama olmayınca resmi bir rapor yazıldı.

Bu yazılım o raporun otomatik üreticisidir.

## Kurulum

Python 3 yeter. Başka bir şey istemez. İstemek ayıptır.

```bash
python3 analizor.py
python3 analizor.py Pamuk
```

## Çıktı örneği

Program size şunu verir:

- kedi adı
- sizin saatiniz (muhtemelen yanlış mesai)
- uydurma ama ciddi bir sebep
- uygulanması imkânsız bir tavsiye
- yüzde ile güven skoru (güvenmeyin, skor kendine güveniyor)
- damga, imza, tarih, isim
